# Coding task rules

Work only in this assigned repository and follow `instruction.md`.
Do not inspect sibling directories, parent work products, earlier agent
submissions, reference solutions, or private grading tests. Do not invoke
other agents or query connected repositories. No network access is required.

Modify engine files under `src/whoosh/`. You may add your own tests under
`tests/`, but must not change supplied task instructions or existing tests.
Retain the existing engine and index format; do not substitute a different
search engine. At the end, summarize implementation, commands executed,
results, and known limitations in `SOLUTION.md`.
